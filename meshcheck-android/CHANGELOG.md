# Changelog

## 0.2.0 - Automatic Sefar identification

- Added automatic reading of the 1 mm ruler shown with the mesh sample.
- Added automatic mesh-pitch and thread-count measurement.
- Added automatic clear-opening estimate and image-quality confidence score.
- Added offline SEFAR NYTAL matching for PA-GG, PET-GG, and AISI 304 Metal Mesh.
- Added material selector, alternate matches, warnings, CSV export, and Arabic reporting.
- Preserved manual two-point calibration as a fallback for low-confidence images.
- Added synthetic automated tests for ruler detection and Sefar catalogue matching.
